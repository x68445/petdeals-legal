# YouTube Studio 수동 설정 (필수!)

## 채널 프로필 링크 추가

1. YouTube Studio 접속 (studio.youtube.com)
2. 왼쪽 메뉴 → **맞춤설정** (Customization)
3. **기본 정보** (Basic Info) 탭 클릭
4. **링크** 섹션에서 아래 2개 추가:

| 링크 제목 | URL |
|-----------|-----|
| 🔥 오늘의 특가 | https://x68445.github.io/petdeals-legal/deals.html |
| 🐾 프리미엄 펫용품 | https://x68445.github.io/petdeals-legal/price_100k.html |

5. **게시** (Publish) 클릭

## 왜 중요한가?

- 소규모 채널은 영상 설명/댓글 링크가 클릭 불가
- 프로필 링크는 항상 클릭 가능 → 유일한 트래픽 소스
- 설정 안 하면 어필리에이트 수익 0원
